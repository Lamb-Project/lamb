# LAMB analytics read adapter (experimental)

Optional Moodle 4.5+ local plugin. Install into `local/lambanalytics` using Moodle's normal administrator-reviewed plugin installation procedure. No institution installation is automatic. Back up the site before installation or upgrade.

The read-only `local_lambanalytics_resource_events` function is registered with the official mobile service. Existing tokens still require active course enrolment and `report/log:view`; separate groups require an authorized explicit group unless the caller has `moodle/site:accessallgroups`. Student tokens do not acquire teacher permissions by installing this plugin.

Parameters: `courseid`, inclusive Unix `since`, exclusive Unix `until`, optional `groupid=0`, `afterid=0`, `throughid=0`, `limit=200`. Windows must be in the past and at most 90 days. The first response establishes `throughid`; retain it and advance with `next_afterid` while `has_more` is true. Permissions are rechecked on every page. Pagination fixes an upper event ID, not an atomic historical database snapshot.

Only allowlisted course views, resource/page/link/folder/book views and book chapter views are returned. Events have log ID, actor ID, module ID, object ID, event class and timestamp. No names, emails, IP addresses, event descriptions or arbitrary event payloads are returned. Actor IDs are not student-role claims. The caller must establish its analytical population separately.

Requires the standard log reader. No events are generated by this endpoint and no extra personal records are stored. Deleted/inaccessible modules are omitted with a count. Group membership and module visibility reflect current state, not historical state. Historical completeness is always unknown: configured log retention cannot establish a complete event history. A logged view does not prove reading, comprehension, download completion or study time.

This is a source adapter, not yet a complete CLI/AAC analytics recipe. It is not a generic SQL or Moodle API execution facility.

Version 0.1.1 adds `local_lambanalytics_resource_scope(courseid, groupid=0, cmids=[])` for saved-evidence authorization. It checks current enrolment, log and enrolment-review permissions, group membership and access to up to 100 resource modules. It returns only the authorized scope, not event or roster data, and does not refresh saved counts. Clients must recheck it on each saved read; the response is not a reusable authorization grant. A removed group membership or inaccessible module prevents readback.
