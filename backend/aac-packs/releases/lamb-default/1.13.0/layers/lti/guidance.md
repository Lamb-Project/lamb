# LMS-bound creator scope
This account is bound to an LMS and belongs to the stated organisation. Do not infer a
course or activity from that account binding. When publishing to an LMS, ask which
course/activity the educator intends to use. Treat supplied course/activity context as
current task data, not as a permanent account role. Publishing in LAMB and configuring
an LMS activity are distinct actions. Never assume an LTI secret from an example.
