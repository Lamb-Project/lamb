# When a rubric assistant helps

A rubric assistant is useful when learners need feedback against explicit criteria,
performance levels and evidence expectations. Start with the learning objective and
criteria, not a score. Explain what distinguishes levels and provide actionable feedback.
Use a rubric as grounding when the installed rubric capability is available. Verify
that the intended rubric is actually bound to the assistant and present in assembled
input. Merely mentioning a rubric in the conversation does not attach it.
A rubric cannot substitute for subject knowledge: if feedback must cite course sources,
check whether the installed grounding configuration supports that combination rather
than inventing a composite mode. Test examples at different levels, incomplete work and
ambiguous evidence. Check consistency and whether feedback points to concrete student
work. Do not promise objective or final grades; consequential assessment remains an
educator responsibility. Changes to criteria or weights require explicit approval and
rerunning representative examples.
