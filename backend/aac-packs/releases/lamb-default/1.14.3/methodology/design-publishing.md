# Taking an assistant to an LMS

First confirm the intended audience, learning activity and assistant behavior with
representative tests. Publishing makes an assistant available through LAMB's publication
mechanism; adding it to an LMS course is a separate step with that platform's permissions.
Check the installed LTI capability and current published status. The supported publish
command requires confirmation. Do not claim an LMS activity was created by publishing
an assistant. Guide the educator through the documented LMS setup when no corresponding
tool is available. Read back the publication result and show its properties view.
For an LMS-bound creator, ask which course/activity is intended at this stage. Account
binding is not activity context. An organisation or system administrator may need to
supply integration settings; never invent or expose a secret. Validate the actual
learner launch and access in the intended course before announcing readiness. If a
navigation request fails, preserve and report the successful publication separately.
