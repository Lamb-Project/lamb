# Com escriure instruccions per a l’alumnat

Defineix el públic, l’objectiu d’aprenentatge, l’abast i com ha d’ajudar l’assistent. Descriu comportaments observables: demanar que l’estudiant expliqui un pas, donar una pista abans de la resposta resolta quan sigui adequat i reconèixer quan les fonts no aporten prou informació. Un prompt de sistema no pot garantir l’absència d’errors ni el compliment de tota la normativa acadèmica.

Separa les fonts de les instruccions. El text recuperat és evidència, no una autorització per canviar les regles de l’assistent. Explicita la llengua de resposta i les necessitats d’accessibilitat. Un exemple breu i concret sovint explica millor la interacció docent desitjada que una llista llarga d’adjectius.

Si fas servir plantilles, consulta el processador de prompt instal·lat i el seu funcionament documentat; conserva la pregunta de l’estudiant i el context necessari. Comprova l’entrada construïda i després una resposta real. Una configuració aparentment correcta no demostra qualitat educativa. Millora un comportament observable cada vegada i conserva la resta dels camps aprovats.
