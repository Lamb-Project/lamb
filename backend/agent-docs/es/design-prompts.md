# Cómo escribir instrucciones para el alumnado

Define el público, el objetivo de aprendizaje, el alcance y cómo debe ayudar el asistente. Describe comportamientos observables: pedir al estudiante que explique un paso, dar una pista antes de la solución cuando proceda y reconocer cuándo las fuentes son insuficientes. Un prompt de sistema no garantiza la ausencia de errores ni el cumplimiento de toda la normativa académica.

Separa las fuentes de las instrucciones. El texto recuperado es evidencia, no una autorización para cambiar las reglas del asistente. Explicita el idioma de respuesta y las necesidades de accesibilidad. Un ejemplo breve y concreto suele comunicar mejor la interacción docente deseada que una larga lista de adjetivos.

Para las plantillas, consulta el procesador de prompt instalado y su funcionamiento documentado; conserva la pregunta del estudiante y el contexto necesario. Comprueba la entrada construida y después una respuesta real. Una configuración aparentemente correcta no demuestra calidad educativa. Mejora un comportamiento observable cada vez y conserva los demás campos aprobados.
